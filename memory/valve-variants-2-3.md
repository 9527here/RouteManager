# 阀门2和阀门3真实接触操作

2026-11-03，详见`docs/其他阀门操作验证.md`。RM65六轴右臂、CTAG2F120、固定台架、
全部96机器人碰撞形状。两个资产独立台架和GUI均完成夹持、转动、松爪、退出。

现象与根因：阀门2默认Prim祖先带0.0011缩放、metersPerUnit=1，不能丢祖先引用。
阀门3是原0～90°扳杆，远端宽6～9mm，整网格15mm宽来自轴毂；按整网格闭爪空夹。
首次双载就停闭爪仍会在9.14°失载；转动预测冻结阀杆又会误判长力臂正常旋转穿透。

修法：`valve_station.py`外摆放内完整引用、发现转轴/刚体；`valve_grasp_region.py`
截取接触区域计算夹宽而保留完整碰撞体。区域可要求在原0.5mm总挤压预算内预紧，
仍过连续双载和0.15s机械停稳。`valve_runtime.py`耦合预测轮轴和关节微段，接触时
每物理步查实际几何。`valve_plan.py`直线超8°递归细分，不改门限。

Fabric下只移动旧工位父USD节点不会更新Kinematic Mount原生目标。空工位迁移需
暂停并更新原生kinematic target和底座/轮体，再预热验轴锚点，不能只看USD变换。

验证：GUI阀门2+91.59887°，滑移0.11780mm/0.22853°，39.00s含预检；阀门3+89.91894°，
滑移0.15700mm/0.67312°，50.58s含预检；底盘均0m/0°。阀门3原生终角89.97454°，
保留原0～90°限位、摩擦.05、无轮轴Drive；阀门2无限轴、摩擦.1。三个源USD SHA均不变。

阀门3最终工位[-.35,-1.3,.94]m、roll180°，轮体局部点[0,.06,-.00345]m、Y半跨度
.012m、`preload_to_bound=true`、TCP轴向+.006m、转动路径速度.8rad/s。低工位不可达
和退出IK超门的失败未算成功。下次须从90°反转，不能正转越限。
