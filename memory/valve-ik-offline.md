# 阀门 IK 离线复核（2026-11-02）

## 现象

10-29 交接后两份阀门脚本仍不能证明 IK 正确；单点反解锚点再 FK 会恒等于零。
本轮不访问服务、不驱动仿真，用历史同批臂座/关节/法兰快照复算 90° dry-run。

## 根因

- `valve_trajectory.py` 把 `(n,6)` 雅可比按 `(6,n)` 切片。
- 两求解器把局部朝向误差配世界角雅可比，`sin(theta)` 在 180° 消失。
- 直接回拉姿态会抵消任务修正。
- 实际正上抓目标在几何可达范围外；数值修复不能解决摆位。
- 旧 `/tmp/linkpose.json` 的 `q_wxyz` 实际存 xyzw；`arm_calib.json` 与该批臂座有漂移。

## 修法

- 两入口共享 `scripts/valve_ik.py`：世界系 SO(3) 对数、雅可比转置、严格零空间偏好。
- 锚点使用同批独立臂座校验法兰，位置 8mm / 朝向 3° 失败即拒绝。
- 新增仅限 dry-run 的 `--snapshot`；旧 probe dry-run 不发指令、不 sleep、不重读。
- 旧序列全部规划达标后才执行；主脚本同时核对法兰与 TCP 残差。
- 主脚本从 URDF 首关节原点及后续平移长度和推导保守可达半径；几何不可达时只求
  一个滚转保留残差诊断，随后拒绝。

证据目录 `outputs/valve_ik_20261102/`（生成文件，未提交），`input.json` 含来源、mtime、
SHA256 与四元数纠正说明；关节/臂座/法兰同批，手轮几何另时刻，均是 2026-10-29 历史量测。

- 实测臂座 FK → 法兰：0.000352mm / 0.000034°，代表快照与同一 URDF 一致性。
- 90° dry-run 退出 1：预接近 295.77mm / 11.49°；盘心 330.08mm / 11.85°。
- 肩到法兰上界 650.480mm；正上抓任意滚转的位置下界分别 203.929 / 259.672mm。
- `scripts/validate_valve_ik.py` 8/8：已知 FK、世界变换、180°、1/7 DOF、独立锚点与防下发。

## 同日可实现方法筛选（只离线，未驱动仿真）

使用同一历史快照筛选到摆位后的完整 90° 运动学候选。相对快照整机沿世界
`+X 0.30m / +Y 0.15m` 平移、`lift_joint` 下调 `0.20m`，roll=0°。
这是假设摆位，不是当前实测位置、导航安全结论或可直接执行的移动量。

- URDF `lift_joint` 范围 `[-0.60,+0.05]m`，历史值 `-0.0021877m`，候选目标
  `-0.2021877m` 在范围内；按历史本体姿态计算实际升降世界轴。
- `outputs/valve_options_20261102/candidate_verified.json`：当前共享 DLS 求解器，
  下降/抬升每10mm、转动每1°，按真实轴线而非固定 mesh bbox 中心生成轨迹，
  包含开合 TCP 无载模型边界，共131点；max TCP残差0.454514mm、法兰0.470959mm、
  姿态0.033543°，最小关节限位余量31.692°，转动段每1°关节最大步幅0.998076°。
- 独立 SciPy 稠密复核（`body_dense_validation.json`）也通过同一候选；另有
  `+X 0.40m / lift -0.20m` 候选，但最小限位余量仅11.52°，无碰撞证据不能据此选定。
- 历史原位任意朝向夹盘心至少差161.800mm；即使夹最近轮缘仍至少差132.710mm。
  原位只升降也不足以完成正上抓。不要把“放开朝向”当成完整解决办法。
- 推荐流程：收臂并完成避碰摆位 → 实测到位 → 对向夹盘 → 接触反馈收紧 →
  按 `T_world_tcp(theta)=T_world_axis RotZ(theta) T_axis_tcp(0)` 连续跟踪 →
  以真实轮轴转角/滑移判完成 → 松爪退出。更大转角可用分段转动后重夹。
- 手轮直径79.9637mm，标定净开口86.2mm，净余量仅3.118mm/边（88.35是指垫中心距）。
  820指令的无载净开口70.6685mm，不能继续当作已验证闭爪量；应实测接触后反馈。
- URDF+mimic 开爪TCP z=246.145676mm，820无载TCP z=250.725801mm，漂移4.580125mm；
  全闭才约11mm。真实夹持会受轮盘阻挡，不会等同于无载820模型。
- 轮轴过历史 `wheel_link` 原点（world Z，localPos1=0）；mesh中心XY偏心0.612255mm，
  固定mesh中心只变yaw会在90°产生约0.865860mm轨迹偏差。夹轮缘时必须走偏心圆弧。

尚未验证：初态到预接近的避碰路径、96形状全身/桌腿碰撞、合爪真实TCP、轮轴阻力矩、
摩擦与滑移。数值残差只说明候选运动学，不代表当前场景或物理操作已成功。
