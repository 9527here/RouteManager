# 阀门夹爪分段提速（2026-11-03）

## 现象与根因

用户发现闭爪很慢。此前所有空行程也按180 position/s（当前86.2mm行程约15.5mm/s）
收紧，阀门3从1000收至102.55需5.14167sim秒，GUI约20wall秒。最终机械停稳窗口
仍只有0.15sim秒，不是主要耗时。

## 修复

`valve_runtime.py`默认空行程1000 position/s；实际指垫内间隙距实测支持宽仅3mm、
指令到3mm慢区边界、或任一指垫出现touching/承载时切回180，单次闭爪锁存慢速，
不会在接触短暂消失后重新快夹；快段目标不能越过慢区边界。缺少有限实际间隙则拒绝。
原0.5mm总挤压、0.15s双承载/机械停稳、接触/避碰/驻车门保留，全部mimic指令变化
逐物理步对照原生速度cap（本机12个右夹爪关节实读4rad/s），不修改cap、K/D或maxForce。

`valve_plan.py`可按实测夹宽+8mm预设接近开口，未饱和时单侧余量4mm。预张开、接近、
下降与闭爪模型统一使用此开口的TCP与mimic；松爪/退出仍为全开TCP。`_prepare`的
初始夹爪扫掠、整段模型和实际初始预置同步用新开口。已有接触入口仍先全开，避免
把恢复松爪当作继续夹紧。纯离线plan默认保持原全开，显式参数可启用预设开口。

CLI新增`--grip-fast-speed`、`--approach-open-margin`、`--grip-slow-margin`；
`--grip-speed`作用于慢段/预紧。诊断记录各阶段精确wall_duration、sim时间及快慢模式。

## 实测

三个阀门GUI均完成转动、松爪、退出，93项相关回归通过。记录根
`outputs/valve_grip_speed_20261103/`，`measured_summary.json`、`postcheck.json`。

| 对象 | 相对转角 | 到位后闭爪sim / wall | 前置预收拢wall |
|---|---:|---:|---:|
| 阀门1 | −89.82196° | 0.450 / 1.750s | 0.064s |
| 阀门2 | +89.94931° | 0.44167 / 1.870s | 1.212s |
| 阀门3 | +89.76753° | 0.44167 / 1.335s | 2.786s |

阀门3到位闭爪sim时间5.14167→0.44167（减少91.4%）；包括前置预收拢为1.25417sim秒、
4.121wall秒。不能把前置时间隐藏成零，也不能将旧粗粒度wall估计当精确benchmark。
本轮阀门3全流程31.682s含预检，滑移0.16443mm/0.68570°；此前反转全流程54.975s，
起点/方向不同，属于同类流程比较。末机械停稳实际0.150000s，原生SDK速度保留。

原生后验：底盘三轮均0m/0°、固定底盘、96碰撞形状、物理view有效、全部轮轴无Drive、
全部指垫已脱离。当前GUI暂停在阀门2完成姿态；阀门3约90°，下一次需按实时轴角选方向。
