# 自动抓取（VR 左手菜单键触发）

2026-10-09 加。按 **左手柄 X 键** → 机器人随机放一个方块到跟前并抓起来。

**不要用菜单键**：那是 Pico 系统键，按下去直接退回桌面（用户实测）。

## 组成

| 文件 | 作用 |
|---|---|
| `grasp_planner.py` | 规划器（纯 numpy/scipy）：`load_chain` / `fk` / `plan` / `plan_grasp`。与 `scripts/pick_object.py` **共用同一份**——两处各留一份会让"TCP 取闭合态"这类关键语义分叉 |
| `robot_manager.py` | `auto_pick()` 启动状态机、`auto_pick_status()` 查进度、`abort_auto_pick()` 中止；`_auto_pick_step()` 在 `step()` 里逐帧推进 |
| `isaac_teleop.py` | `_tick` 读**左手 `PRIMARY_CLICK`（X 键）**，边沿触发置 `_menu_req`；`consume_menu_request()` 由主线程取走；`set_suspended()` 在抓取期间挂起 VR 手臂/夹爪写入 |

## 状态机（必须非阻塞）

`reset → spawn → open → measure → plan → plan_tick → body → reopen → pre → descent → close → ascent → settle`

- `pre`：**一步到物体上方悬停位**（关节空间插值 2s），然后 `descent` 垂直下压。
  试过加笛卡尔接近路径，反而变成"先往上、再从上面接近"，用户 2026-10-09 明确
  要回到 `pre` 这一版。

默认 `randomize=True`（X 键）：**固定抓黄色方块 `cube_c`，只随机它的落点**
（用户指定"就一直只随机黄色物体位置"）。`_GRASP_DEFAULT_OBJECT` 可改。

**不能从 HTTP 协程里同步跑**：`send_joint_command` 的插值靠主线程 `step()` 推进，
同步等会死锁。所以每个 phase 只发一次指令（用显式 `sent` 标志，**不要用
`el < 0.05` 这种时间窗**——一帧卡顿就漏发），然后等够时间或等 `_motion is None`。

- `reset`：**先把机器人送回桌面正前方标准位 + 手臂回 home**。用 VR 把机器人
  开走之后，随机摆放的可达范围就对不上了（用户要求"按 X 先复位到桌前"）。
- `plan` / `plan_tick`：规划是**生成器**，每帧只试一档机身高度。一次完整规划要
  跑上百次 least_squares，同步跑完会把画面冻住十几秒（用户实测"按了 X 卡顿很久"）。
  分帧后规划只占 ~0.6s，且第一档够好就提前退出。
- `spawn`：先把机身复位到 home（可达范围是按 home 位姿标的，机身还停在上一轮
  降下来的位置时臂基座会整体前移 0.2m+，物体被放到够不着的地方），再随机放物体。
  **其它物体一律不动**（用户明确要求）。只从落点上避开它们：随机抽 12 次，
  取第一个离其它物体 >0.18m 的点。
  **可达范围用机器人 `base_link` 系算，不要用臂基座**——后者随机身升降/俯仰漂移，
  实测同样 z 下 x 能从 −0.04 变到 +0.19。前 0.44~0.58、侧 0.05~0.31（左臂在 +y）。
  规划失败会自动把物体挪近 6cm 重试（最多 3 次）。
  侧向范围 **偏左手边**（+y，左臂那一侧）：`lateral=(0.20, 0.38)`，实测落点
  y≈0.23~0.32，姿态更松更好够。
- 只随机**落点**，不随机物体、也**不动其它物体**：`_GRASP_DEFAULT_OBJECT =
  "cube_c"`（黄色），侧向偏左手边。
- 候选物体筛选也要用 `_object_true_size()`：物体被夹住倾斜时 AABB 会胀到 84mm
  （60mm 方块转 45°），用 AABB 筛会把在场物体全过滤掉 → 报"场景里没有可抓物体"。
- 物体尺寸要用 `_object_true_size()`（读 Cube.size/scale），**不能用 AABB** ——
  70mm 的方块转 5° AABB 就量成 75.6mm，算出的开口会让指垫碰不到物体。
- 物体带随机 yaw 时，把虎口候选方向对准它的面（法向+切向 4 个方向），
  见 `plan_grasp(jaw_axes=...)`。
- `measure`：先合到**目标闭合角**再量 `tcp_local`（指垫中点随开口漂移 ~11mm）。
- `body`：规划会搜机身升降高度（`lift_joint`），选姿态误差最小的那个再移过去。
- `descent`/`ascent`：**笛卡尔直线路点**，不能用一个 `send_joint_command` 走完
  ——关节空间插值会让 TCP 走曲线、斜着蹭到物体（实测把物体推走 4cm）。
- `settle`：**任务级自检 + 重放重抓**。抬完看物体有没有真的跟着起来，没起来就
  重放重抓（最多 2 次）。单次物理成功率只有 ~50-70%，靠重试把整体拉到 **5/5**。
- 抓取用**过盈 0.5mm**（摩擦修好后不需要靠过盈硬挤；过盈大反而穿模）。
- `close`：**闭合自检 + 自动补夹**。位置驱动有稳态误差（力矩上限/刚度），实测
  指垫会停在离目标 0.5~1.4mm 处 → 没真正接触 → 一抬就掉。闭合后量实际中心距，
  差多少就往紧里再补多少（最多 3 次）。**这是把成功率从 3/4 提到 9/9 的关键。**
- 按键分工：**左手 X = 自动抓取**，右手 A = 复位（原来是 A/X 都是复位），
  B/Y = 回 home。`randomize=False` 时退化为"抓夹爪附近最近的物体"（`max_dist`）。

## 验证过的

- 随机摆放 + 抓取端到端跑通：随机放到 (0.537, 0.233) yaw 62°，虎口自动对准
  旋转后的面，IK 误差 0.0mm，机身自动降 0.24m，抬起 **Δz=+0.199m**。
- 加"闭合自检 + 自动补夹"后最好的一批 **9/9**（4/4 + 5/5），但**稳定性一般**：
  单次物理成功率 **~50-70%**（多批实测 4/4、5/5、3/4、1/3、1/4、3/4），失败形态是
  "指垫停在离物体面 0.5~2mm 处没真正接触，一抬就滑"。**加"任务级重放重抓"后
  实测 5/5**（每次最多重试 2 次）。过盈调大到 1.5mm 反而更差——指垫嵌进物体
  3.5mm，物体被挤出去。
- 更早出现过夹爪主动关节跑到 **−0.4368**（越过 [0, 0.7] 限位、指垫只分开
  40.9mm）的机构偶发失稳，见 [[gripper-mimic-chain]]。
- **补夹有跑飞风险**：加压太多时指垫反而**张开**（实测一路压到 51.6mm 时指垫
  张开到 64mm），所以累计补夹量设了 3mm 上限。

## 可靠性还差什么（下一步方向）

指垫闭合到"离目标 0.5~2mm"就停住，是**位置驱动 + 四连杆**的稳态误差叠加接触
刚度问题。可试：
1. 把夹爪关节从纯位置驱动改成**带力控/柔顺**（或降低刚度、加接触阻尼）；
2. 抓取后用**接触力/接触对**判定是否真的夹住，没夹住就重试整个流程；
3. 给指垫换成**真实的软垫材质**（高摩擦 + 低刚度），别用刚体硬碰。
