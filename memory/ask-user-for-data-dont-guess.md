用户原话（2026-09-21）："以后有什么需要获取的数据一定要给我说，不要自己猜。这样我也好找同事要。"

**Why:** 相机/机器人项目里我多次用推定值（质量估值、FOV 推定、无预留结构时自定安装位），用户可以直接找机械/同事拿到权威数据；猜的值会带进 URDF/仿真并被当成事实。

**How to apply:** 遇到规格书数值、机械安装位、结构决策类信息缺口时：(1) 明确标注"推定/待核实"，不要写成确定值；(2) 主动整理成一份可执行的"找同事要数据"清单给用户（写明要什么、向谁要、拿到后改哪里）；(3) 拿到权威数据后替换并复跑相关校验。相关项目背景见 [[gripper-swap-task]]。
