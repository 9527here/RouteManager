# 阀门GUI提速（2026-11-03）

## 实测慢在哪里

慢速GUI运行期24.8875sim秒用了220.8616wall秒（5974步，平均36.97ms，240Hz预算4.17ms）。
暂停只读30次采样：capture10.80ms、Safety.refresh3.86ms、小步扫掠10.07ms、邻近IK2.78ms；
暂停render约5ms。实际cProfile又发现属性面板每物理步响应大量USD属性变化。
`outputs/gui_valve_20261103/performance_before/`是原采样，after是优化与等价性检查。

## 修法与保留的约束

- `valve_feedback_cache.py`：缓存不可变网格/关节帧/固定链/接触报告配置，不缓存q/v、
  接触事件或刚体位姿。原生RigidBodyView批量读阀体/手轮/夹具，机器人Tensor每步新读。
  USD notice对缩放、points、CollisionAPI、隐藏形状、约束与静态障碍改变失效；
  动态刚体平移/旋转只忽略元数据失效，实际Pose仍每步新读。关闭时Revoke自己的订阅。
- 共享同一物理步的位姿给ValveSafety，仍读实际全身/环境。采样capture0.98ms、refresh0.84ms、
  小步扫掠约5.11ms（后续距离缓存/向量化前）；慢/快反馈的q、TCP、jaw与轮轴角比对相同。
- CollisionModel XYZ旋转用sin/cos替代通用SciPy分派；20个随机全身FK与旧实现差≤8.88e−16。
  角点向量化复用，平面检测同样覆盖全部形状。旧/新12组完整几何结果与采样数相同，
  含安全与拒绝；另有故意下沉地面拒绝案例。
- 距离缓存只在不变几何下按完整世界矩阵的字节相等复用；预测的机器人内部对还可按
  LCA以下相对关节坐标字节相等复用（公共祖先刚体运动严格相消）。实际Pose查询不走
  相对FK缓存，几何变更由guard停止，未用近似舍入或冻结动态状态。
- 60Hz IK/控制周期先检查完整插值段，再逐240Hz物理步发送位置/速度前馈并采样。
  原2mm/0.01rad扫掠精度、实际几何25Hz、每步接触/驻车/滑移/轮轴检查均保留。
- 默认通用1.2rad/s、转动2rad/s（原生六轴cap3.14）、收紧180/张开400单位/s，阶段.25s。
  没有改K/D/质量/惯量/maxForce。只给右臂6关节速度前馈，段末与失败清零；实测50维速度
  目标均恢复原值。全局速度参数不带turn覆盖时会同步到turn。
- `SimulationManager.enable_fabric(True)`是官方快位姿通路，关闭physics updateToUsd等4项，
  GUI原本已使用Fabric SceneDelegate。暂停切换前后q/targets/kp/kd/force逐项相同、view有效、
  shapes96；不是改变物理dt。动态控制必须继续用Tensor，USD authored pose可能不再跟随。
- 运行中临时取消选中（原选中ground geom），结束恢复，避免Property Widget刷新；不强制
  覆盖用户在执行中重新选择的对象。IK按TCP精度分配DLS平移/角度预算，减少LS回退。
