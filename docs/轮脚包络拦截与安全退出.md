# 轮脚包络拦截与安全退出

2026-11-02用户反馈反复显示“当前身体/手臂包络已接近障碍，禁止直接带碰撞走位”。实际起点为base XY约(0.318,-0.780)m、yaw约-10.6°，比演示操作位更靠近台架。

## 查明的问题

当前并非手臂撞柜：手/臂最近环境间隙约0.242m，整体机器人除地面外最近真实间隙为底盘防撞包络与脚座之间19.34mm；前左轮与主工位脚之间23.47mm。旧投影盒和整高度扫掠圆却报告5.91～107.79mm重叠。轮胎是圆柱，3cm高脚座只邻近轮胎下部，不能把轮轴高度最宽处的XY半径套到轮胎全高；用8角Cube包轮后再施加滚轮自转，也会夸大圆柱投影。

但不能简单忽略粗碰撞：保持当前约[+90,+90,-90,-90]°舵角时安全，原地回正到0的实际扫掠会使前左轮穿入脚座，最深约8.96mm。问题是“当前姿态可保持，但下一次转舵有风险”，旧逻辑没有安全退出阶段，只会一律拒绝。

## 修复

- `scripts/navigation_narrowphase.py`以当前PhysX位姿、96个机器人形状和环境真实3D形状复核。粗盒/圆只负责列候选，最终不再以它们的重叠直接判碰撞。
- 明确排除机器人自身对和已确认地面支持，保留所有台脚、支腿、柜壳与非操作手臂。距离非有限则停止，12mm全身体保护阈值不降低，手臂5cm规则继续独立执行。
- 每段平移按即将使用的舵角核验路径，转舵另作0.25°步长FK扫掠。近障碍时，Y轴零位分支不确定还会核对两组可能方向；实际换轴前再复核。
- 如果当前真实净空通过，但普通转舵/路线被挡，搜索沿当前已对齐的轮向低速退出20～25cm。退出平移按2mm步长精确验证，确认之后能安全接上原路线才执行。全程车身朝向保持、wz=0，不瞬移或搬动台架。
- 当前真实已碰撞或没有安全退出路径时仍拒绝，不能用恢复功能继续压入障碍。动态收臂前的驻车回正也加了扫掠检查，不能先回正撞脚再考虑退离。
- UI对无pending的失败/取消/完成也同步终态，且每个终态只处理一次；`request()`同步失败不再被覆盖成“已开始/正在准备”，不会错误排入机构动作。

## 本次验收

`outputs/envelope_recovery/`保存了只读审计、虚拟原起点重放和实际恢复：

- `navigation_envelope_audit.json`：当前真实无碰撞与粗包络误报对照。
- `exact_steer_sweep.json`、`requested_recovery_sweeps.json`：原地回正不安全；保当前轮向沿Body -Y退出25cm全路径安全，Body +Y不可行。
- `turn_after_lateral_exit.json`：退出5cm仍不安全、10cm余量不足12mm，15cm以上回正扫掠通过。
- `live_exit_validation.json`：实际低速退出19.57cm，Body X偏移4.60mm，未瞬移、全程wz=0、全身真实净空与手部规则通过。
- `autorecovery_plan_validation.json`：用原起点和原90°舵角做只读FK验证，自动找到-Y20cm→X退离→Y接近原目标，机器人没有被推回脚座重演。
- `original_action_retry.json`：原来被拦的圆座扁柄三档选择开关已切至45°，首次机构动作时at_target和stationary均true。

日常远离台脚的情况仍使用轻量粗筛，靠近障碍才作窄相复核。这是当前静态工位的恢复，不代表能从任何真实夹碰/动态障碍场景自动脱困。

## 默认自动回退（2026-11-02 用户要求）

插件现在默认自动处理已收臂走位中的转舵或前方通道受阻，包括起步规划和运行途中：先进入`recovering_stop`，确认真实停稳后刷新当前几何、舵角和障碍位置，再按10、15、20、25cm逐级寻找保轮向且能接回原目标的最短安全退出。退出全路径同时要求全身12mm、双手/臂50mm净空，车身朝向保持，轮速上限仍为参考0.025m/s。固定退出20cm的现场验收触发过累计2°偏航保护，原始失败报告保留，不能通过放宽保护来让验收过关。

资产操作的待办在回退期间保留，到位停稳后只执行一次原动作；手动左/右移受阻则安全退出并显示“本次横移未完成”，不会绕前后轴后冒充纯横移。每次请求最多自动回退一次，配置为`mobile_operation_profile.json`的`automatic_recovery_max_attempts: 1`。回退失败、没有安全路径、真实净空不足、姿态/反馈异常仍停止。准备收臂前的回正受阻不自动移动未收好的双臂。

“停止底盘”或“停止全部”立即取消回退及待执行操作，后续帧不会自行恢复。只有明确的`NavigationBlocked`受阻信号能进入自动恢复；距离非有限、几何读取失败等普通异常直接终止，不能被当作换一条退出路径重试。
