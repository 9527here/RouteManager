# 项目目录与文件管理

本次整理围绕一站式工厂仿真配置、任务/可达性验证、Isaac Lab批采与Real→Sim→Real组织入口，没有批量改动运行期控制算法。

| 层次 | 保留内容 | 管理方式 |
|---|---|---|
| 核心 | 启动、HTTP执行器、机器人控制、FK/规划、夹爪与底盘 | 根Python模块与ros2_bridge，保持既有导入路径 |
| 可复用任务/工具 | 电柜、阀门、资源接入、资产转换、采集、诊断 | scripts，按文档导航进入，不凭文件名删除依赖 |
| 离线回归 | 17个unittest模块 | tests/test_*.py，共享纯Python导入bootstrap |
| 原生验收 | 实际Kit/HTTP/数据文件检查 | scripts/validate_*.py，明确区分会启动Kit或操作现场的入口 |
| 资产描述 | 参数、来源、目录、少量既有源描述 | assets；大模型、原CAD、转换缓存和纹理不入新提交 |
| 实测与研究 | 失败、标定条件、数据契约 | memory与docs，保留日期和边界，不把旧实测改成新结论 |
| 本机产物 | USD现场、HDF5、图像/录像、日志与几何快照 | outputs留原位并全量忽略，避免破坏现有USD引用 |

旧`humanoid_upper_body_v3`资源包完整移到`~/RouteManager_assets/legacy/`，原路径保留软链接；已跟踪部分有hash清单和历史恢复脚本。
从Git当前树移除不会缩减既有Git历史；此次没有重写历史。参见[资产说明](../assets/README.md)。

移出的无关文本样本、5个未被功能入口引用的相机试验脚本和整理前源码备份在本机
`/home/jy/data/repo-backups/RouteManager/20261103-restructure/`。该目录含原索引与二进制patch，按私有备份管理，不上传。
生成背景图片只取消Git跟踪，文件仍在本机。共享image-analyzer技能改为指向单份源文件的软链接。

不要自动移走活动现场的`outputs/`、删除正在引用的外部USD依赖，或把`arm_calib.json`、安全策略、姿态与机构参数当普通缓存清理。
新增任务先记录资产与机器人身份，再提交可复用代码、说明和回归；数据和验收大件保留可追溯路径，不用`git add .`混入源码。

README面向人类，AGENTS.md是唯一权威agent约束，`.claude/CLAUDE.md`只保留导航。仓库内memory属于项目事实记录，与用户目录下的agent记忆分开。

| 入口 | 只负责什么 | 何时更新 |
|---|---|---|

| 根`TODO.md` | 统一现状、发布/本机研发边界、优先事项和验收条件 | 功能、缺口或验收结果变化 |

不再在首页、导航和多个专题重复路线图。普通操作尽量在使用手册内完成，细节和原始结论通过页末折叠参考进入。现有专题路径先保留，避免破坏外部链接；按TODO中的DOC-03逐篇提炼正文。

新增教程先写适用模型/版本与前提，再给命令、输出、成功判据和停止方式。暂未实现的步骤进入TODO；历史失败不能删除或混写成当前成功。完成条目保留ID和验收范围，不能仅因有代码就打勾。

参考了[Isaac Lab](https://isaac-sim.github.io/IsaacLab/main/index.html)对快速开始、教程、概念和API的分层，[ManiSkill用户指南](https://maniskill.readthedocs.io/en/latest/user_guide/index.html)对任务/机器人、数据采集和Sim2Real的组织，以及[robosuite](https://robosuite.ai/docs/overview.html)对入门、模块、教程和参考接口的区分。本项目据此先用Markdown收拢常用工作流，文档站和搜索留待内容稳定后评估。

本机外部资产入口由`link_asset_library.py`重建，Git忽略`third_party/vla_assets`。它是目录链接，不是Git子模块；不改变已有预设、活动场景或源资产。统一路径解析和逐资产版本清单分别由CFG-01、ASSET-02继续完成。
