# 项目目录与文件管理

本次整理围绕一站式工厂仿真配置、任务/可达性验证、Isaac Lab批采与Real→Sim→Real组织入口，没有批量改动运行期控制算法。

| 层次 | 保留内容 | 管理方式 |
|---|---|---|
| 核心 | 启动、HTTP执行器、机器人控制、FK/规划、夹爪与底盘 | 根Python模块与ros2_bridge，保持既有导入路径 |
| 可复用任务/工具 | 电柜、阀门、资源接入、资产转换、采集、诊断 | scripts，按文档导航进入，不凭文件名删除依赖 |
| 离线回归 | 17个unittest模块 | tests/test_*.py，共享纯Python导入bootstrap |
| 原生验收 | 实际Kit/HTTP/数据文件检查 | scripts/validate_*.py，明确区分会启动Kit或操作现场的入口 |
| 资产描述 | 参数、来源、目录、少量既有源描述 | assets；大模型、原CAD、转换缓存和纹理不入新提交 |
| 实测与研究 | 失败、标定条件、数据契约 | memory与docs，保留日期和边界，不把旧实测改成新结论 |
| 本机产物 | USD现场、HDF5、图像/录像、日志与几何快照 | outputs留原位并全量忽略，避免破坏现有USD引用 |

旧`humanoid_upper_body_v3`资源包完整移到`~/RouteManager_assets/legacy/`，原路径保留软链接；已跟踪部分有hash清单和历史恢复脚本。
从Git当前树移除不会缩减既有Git历史；此次没有重写历史。参见[资产说明](../assets/README.md)。

`/home/jy/data/repo-backups/RouteManager/20261103-restructure/`。该目录含原索引与二进制patch，按私有备份管理，不上传。
生成背景图片只取消Git跟踪，文件仍在本机。共享image-analyzer技能改为指向单份源文件的软链接。

不要自动移走活动现场的`outputs/`、删除正在引用的外部USD依赖，或把`arm_calib.json`、安全策略、姿态与机构参数当普通缓存清理。
