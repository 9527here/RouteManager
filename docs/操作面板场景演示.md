# 操作面板场景演示（2026-10-30）

已在当前 Isaac Sim 6.2 / RouteManager 的人形＋动力柜场景加入面板，路径
`/World/OperationPanel`。面板位于柜体侧边；展示支架仅用于排布，尺寸不代表实物规格。
没有在 3D 场景增加铭牌，也没有注册机器人相机。

## 看什么

- 上排：隔离旋转开关、急停按钮。
- 下排：安全手柄开关、Schneider 断路器 CAD。
- 循环约 39 秒：旋钮切换/保持/返回 → 手柄切换/保持/返回 → 急停按下锁定 → 旋转解锁 → 回位。
- 断路器 CAD 保持静态，没有添加推定关节。
- 这是**关节驱动机构演示，人形保持原姿态，没有通过人形手指接触这些新机构**。
  急停的按下后旋转解锁仍不同于目标动作文档的先转外圈再按中心。

## 窗口控制

Isaac 窗口中的 `Operation panel demo`：

- `Start loop` / `Stop`：启动循环 / 停止并恢复源 normal 驱动增益。
- `Overview`：人形、动力柜和新面板全景。
- `Panel close-up`：面板近景。
- `E-stop detail`：急停近景；圆柱外观旋转对称，实际角度可看窗口里的 deg 读回。

窗口显示当前步骤、旋钮/手柄角度、急停行程/扭角/状态。按钮不会控制人形手臂。
当前已启动循环；停止后仍保留面板和原人形场景。

也可从项目根执行：

```bash
python3 scripts/operation_panel_demo.py stop
python3 scripts/operation_panel_demo.py start
python3 scripts/operation_panel_demo.py start --once
python3 scripts/operation_panel_demo.py overview
python3 scripts/operation_panel_demo.py closeup
python3 scripts/operation_panel_demo.py estop
python3 scripts/operation_panel_demo.py status
```

## 插入方法的边界

本次没有重复 `load_robot`。在原 World 里保存当前实际根位姿和关节位置，将其设为 reset
默认值，stop → 添加新引用（不删除/停用原 prim）→ World.reset → 原 articulation
`_on_physics_ready(None)` → 恢复关节位置/速度与目标 → 初始化新机构 view。
只有新 view 建好后才注册状态机和演示回调。过程针对本项目当前 50 DOF 人形验证通过，
不能据此认为任何运行期场景修改都安全。
