# L3 前端展示资产可用性（2026-10-30）

结论：**能用作电柜控件的外观与改造底模，不能直接当作已经能操作的仿真机构。**
其中 object_14.glb 的螺丝压板外观候选值得优先拆件；按钮/旋钮可补现有柜体的视觉。

## 本轮实查

源目录 `/home/jy/datasets/vla_data/L3_前端展示/` 约 53 MB，只有 `model/` 和
`model(1).zip`。model 内 23 个 GLB，ZIP 内也是同一批23文件，CRC与逐字节哈希均匹配，
并没有额外一套可操作版本。此次没有修改源目录，没有把这些资产加进当前演示场景。

- 23/23 用 **Isaac Sim 6.2** 独立进程成功转为 USD，贴图依赖完整，正背两侧共46张预览。
- 每个 GLB 都是 1 个 Mesh、1 个 primitive、2 个 scene node，无动画、骨架或物理扩展。
- 转换后总计 **0 关节、0 刚体、0 碰撞体**；USD 转换只解决加载格式，不会生成机构行为。
- 源坐标最长边范围约 0.9906–1.0004；高度/宽度表现出归一化特征，不能据此认作真实1米。
  转换后 metersPerUnit=1 只是格式单位，真实比例仍需设备尺寸确认。
- USD upAxis 元数据为 Y；最终安装朝向需按各模型外观确认，不套用统一翻转。
- 网格来自纹理化表面，模型文字有模糊/不完整处；不能据此确认具体型号、档位、电气用途。

## 优先级与改造工作

### 1. 螺丝压板：object_14 优先

在按顶点位置焊接、排除 UV 接缝影响后，object_14 有 **4 个较大连通分量**，面数分别
5542/4534/4364/3088。位置和外观支持把它们作为底座、上下螺帽、中间部件的候选，
但连通分量不等同已确认的语义零件或约束。

object_13/15 各1个连通分量，object_16有2个，object_111有1个。它们目前既没有螺纹、
旋松/锁紧状态，也没有压板摆动约束。object_14 可优先尝试拆分并保留UV/材质，再补
碰撞、关节、松紧与投退联动；不能只给整体加一个旋转关节，就宣称“旋松＋拨动”通过。

还需确认：实物尺寸、活动件身份、转轴/摆动方向、旋松余量/锁紧判据、导电投退状态、
25 mm 净空与至少5轮循环。不能从归一化网格量取这些毫米规格。

### 2. 旋钮与按钮：先复用外观

- object_3–5 可优先对接已有旋钮刚体和转轴，需核对物理包络与外观一致。
- object_6/19 含固定面板，整件一起旋转会把面板也转走，必须拆出活动旋钮或重建几何。
- object_0 (1)/1/2 的按钮/灯身份未确认。按钮需要直线行程/回位、灯需要发光材质与
  电气状态映射；当前亮色贴图不是已实现的点灯控制。
- 圆形红头不等同目标“先转外圈再按中心”的复合急停。

### 3. 不能由这批直接补齐的动作

提拉压板的导向/落孔、复合急停的独立外圈、断路器合分闸机构、钥匙/锁芯/锁舌与柜门
联动均没有得到结构证据。因此本轮新增完整人形动作验收仍为 **0/22**，但新增了此前
缺少的螺丝压板外观与拆件候选。

## 文件与复现

- `scripts/inspect_glb_assets.py`：系统读取GLB结构后，用独立Isaac6.2转换并预览。
- `outputs/l3_inspection/audit.json`：23文件哈希、GLB结构、USD单位/方向/物理/依赖。
- `outputs/l3_inspection/topology.json`：按位置焊接后的连通分量，不是语义标注。
- `outputs/l3_inspection/classification.json`：逐文件候选用途与边界。
- `outputs/l3_inspection/usd/`：试转的USD与贴图，分析派生文件，不替换源资产。
- `outputs/l3_inspection/key_candidates.jpg`、`catalog_opposite_1.jpg`、`catalog_opposite_2.jpg`：外观索引。

首轮从背面看见大量黑色背盖，不能误判贴图丢失或把铭牌背面当作操作压板；第二轮
相反视角确认了正面文字和活动件外观。原材质还省略 metallicFactor，按glTF默认值
导出为metallic=1，正式视觉使用需核对塑料/涂层材质，不直接当作实物材质标定。

复现示例（在项目根，ISAAC_PYTHON 指向本机6.2解释器）：

```bash
env -u DISPLAY -u VIRTUAL_ENV -u PYTHONPATH -u LD_LIBRARY_PATH -u ROS_DISTRO \
  OMNI_KIT_ACCEPT_EULA=YES PYTHONUNBUFFERED=1 \
  "$ISAAC_PYTHON" scripts/inspect_glb_assets.py \
  /home/jy/datasets/vla_data/L3_前端展示/model --output outputs/l3_inspection --opposite
```
