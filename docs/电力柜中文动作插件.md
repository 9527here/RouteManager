# 电力柜中文动作插件

在当前 Isaac Sim 6.2 场景右侧使用 **电力柜动作控制**。先在实际机构名称列表选择资产，再点击动作；面板会显示实际行程、角度、灯和压板状态。编号对应原 L3 文件，`0 (1)`、`6 (1)` 对应同名变体。

## 已接入的操作

| 资产 | 按钮 | 执行结果 |
|---|---|---|
| 4 个按钮：0、0 (1)、1、2 | 按下并保持（亮灯） | 施加按压力，按下后保持，灯随实际行程亮起 |
| 同上 | 松开复位（灭灯） | 撤除按压力，弹簧回位后灯灭 |
| 同上 | 按压并复位 | 自动完成一次按下、释放 |
| 两档旋钮：3、6、6 (1) | 切至 0° / 切至 90° | 施加扭矩旋至目标档，撤除后靠卡位保持 |
| 三档旋钮：4、5、19 | 切至 -45° / 0° / 45° | 同上；不适用的档位按钮禁用 |
| 5 个压板：13、14、15、16、111 | 投出（旋松后拨开） | 上下螺母分别旋松，再将压板拨开至约 90° |
| 同上 | 投入（拨回后旋紧） | 拨回压板，再旋紧上下螺母，反馈锁紧状态 |
| 当前人形右手、绿色按钮 0 (1) | 人形右手：按压绿色按钮并复位 | 根据当前机器人姿态规划，指垫实际接触按压，松开后回撤 |

机构直接操作采用物理力/扭矩驱动。人形操作单独列出，目前只接入绿色按钮的真实接触流程；其他按钮、旋钮和压板尚未完成人形接触闭环。

### 动力柜与迁移机构

展开同名折叠区域，可操作当前已加载的旧机构。没有加载相应资产时，对应按钮禁用；插件不会自动更换场景或重载机器人。

| 资产 | 中文按钮 | 执行方式 |
|---|---|---|
| 动力柜 Btn04～Btn07、Lock_Btn | 按下并回位 | 原关节驱动，按压后回零，检查刚体相对关节锚点的实际反馈 |
| 动力柜 Knob01、Knob02 | -45° / 0° / 45° | 原关节驱动，检查实际角度 |
| 动力柜顶部 Btn01～Btn03 | 点亮 / 熄灭 | 切换发光材质，只表示视觉灯态 |
| Oxford 隔离开关 | 转至 0° / 90° | 沿用已验证机构驱动与逻辑阈值 |
| Oxford 安全手柄 | 转至 0° / -90° | 同上 |
| Oxford 急停 | 按下锁定 / 旋转解锁并回位 | 分阶段执行按下、旋转、释放、转回，并检查实际位置和锁定状态 |

以上均为直接机构操作，机器人保持原状态。Oxford 动作临时沿用此前演示的机构驱动值，完成或停止后恢复。动力柜锁柄到位验证失败、静态断路器和柜门等动作未开放。

## 使用方式

- 正在动作时，资产选择和冲突动作禁用；按住按钮时仍可点击“松开复位”。
- **停止当前动作**：直接机构动作撤除外力；人形动作停止下发轨迹并保持当时手臂位置。停止不会自动重置压板或旋钮，随后可继续选择目标动作。
- **查看全部资产 / 查看选中资产 / 查看人形**：只调整视口，方便观察。
- “完成”由实际机构反馈判定；转动超时会停止并显示“未到位”，不会继续后续步骤。
- 如果关闭窗口，在项目根执行 `python3 scripts/l3_station.py all` 可重新打开，当前已安装场景不会重复加载机器人。

## Isaac Lab 批量采集

在面板下方 **Isaac Lab 批量采集** 中选择任务、每动作回合数、并行环境数和输出父目录，再点击 **开始批量采集**。默认 4 个并行环境、每动作 10 回合；每次新建独立目录，避免覆盖已有数据。勾选彩色图像会增加显存与磁盘占用。

采集在独立的 Isaac Lab 进程中运行，使用单独的场景和重置流程，桌面当前人形不会随采集重置。首轮启动需要等待 Isaac 就绪；进度从采集目录的 `progress.json` 更新，启动日志为 `launcher.log`。点击 **停止采集并保存** 后写入 `STOP` 请求，由采集循环保存并安全退出。该按钮和上方 **停止当前动作** 分别控制采集进程和桌面动作。

本轮批量入口覆盖 L3 的 33 个机构任务：4 按钮各按压/复位、6 旋钮共 15 个目标档、5 压板各投入/投出。**全部动作** 指这 33 个任务。动力柜、Oxford 的桌面控制和人形真实接触不混入这批直接机构操作数据；后续替换带外壳的人形模型后，再统一验收机器人接触任务。

等价命令：

```bash
bash scripts/collect_l3_isaaclab.sh --num-envs 4 --episodes 10 --tasks all --output outputs/l3_isaaclab/手动采集
```

可用任务为 `all`、`button`、`selector`、`plate`；`--episodes` 表示每个具体动作的回合数，可加 `--rgb` 保存彩色图像。场景参数仍为参考规格，数据不能作为真机按压力、扭矩或电气状态标定。

## 与动作梳理的对应

对应《电力柜动作梳理》的旋钮目标档/复位、按钮灯亮/灯灭、目标按钮按压/复位、螺丝压板投出/投入。旋钮暂按角度标记：未确认型号和接线前，不把某个角度写死为“远方/就地”或“合闸/分闸”。普通红按钮也不标成急停。既有 Oxford 演示与动力柜动作不计入本次这 15 件 L3 操作入口。

全部参数为参考规格，待实物标定。仿真灯和逻辑状态不等于真实电气通断；该版本不能作为实物按压力、旋钮扭矩或压板锁紧扭矩的标定依据。

## 实现与验证记录

- `scripts/l3_action_plugin.py`：中文界面、动作编排、到位反馈、互锁和停止。
- `scripts/l3_station.py`：物理力/扭矩执行、场景安装及入口。
- `scripts/l3_robot_contact.py`：人形真实接触与取消检查。
- UI 人形按钮通过本机 HTTP 提交到仿真主线程；后台线程不访问 USD/物理对象。
- `outputs/l3_operable/live/chinese_plugin_checks.json`：中文动作回调与机构反馈验收。
- `outputs/l3_operable/live/plugin_robot_result.json`：从中文人形按钮入口执行的真实接触结果。
- `outputs/l3_operable/live/chinese_actions_ui.png`：当前中文面板截图。

- 15 件机构的中文回调验收 **59/59 通过**：保持/释放/单次按压、档位、压板投退、冲突互锁和机器人物理视图。
- 从“人形按压”入口完成 1 次真实指垫接触：行程 **3.147 mm**，最大接触冲量 **0.02057 N·s**；松开回位，按钮预载目标未改变，整机反馈有限。
- 中途停止验证通过，右臂停止后最大关节漂移 **0.000338 rad**；记录 `plugin_cancel_result.json`。
- 当前站位偏移后采用 **-10°** 接近方向，规划路点最大位置残差低于 **0.001 mm**。规划允许在±20°内选择方向，所有路点保持1mm/1°求解门限；仍不可达时显示站位提示，不执行轨迹。此为当前站位演示验证，不代表任意站位都可按压。
- 可重跑机构验收：`python3 scripts/validate_l3_action_plugin.py`。该命令会实际操作当前15件机构，请在空闲时运行。

### 自碰撞工作暂缓（2026-11-02）

按用户要求，自碰撞专项等待带外壳的新机器人 URDF。插件设置 `_defer_self_collision=True`，停用旧软件守卫对动作的拦截，人形按钮不再以前一版守卫安装为前置条件。此设置不修改正在运行场景的物理自碰撞 API，不宣称现有裸机已完成全身避碰验收。原始诊断和副本试验保留在 `memory/l3-return-self-collision.md` 与 `outputs/collision_guard/`。

新增采集启动/停止协议已通过 8 项隔离检查：参数传递、环境变量隔离、防重复启动、进度读取、停止请求、文件关闭、无效参数和暂缓守卫。实际 Isaac Lab 采集验收以采集目录中的结果为准。
