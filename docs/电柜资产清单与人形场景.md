## 从空白 RouteManager 服务复现

```bash
python3 scripts/cabinet_inspect.py setup --repair \
  --asset /home/jy/VLA/simManager/data/environment/dongligui/dongligui.usd \
  --position 1.1 0 0 --yaw 180 --output outputs/cabinet_humanoid
```

然后把 `scripts/scene/setup_cabinet_humanoid.py` 全文作为 `POST /python` 的 `code` 执行。

使用新的服务会话。机器人已加载时，脚本会拒绝重复加载。
