# USD001 新资产与电力柜动作对应

日期：2026-10-30。按用户要求，以外观候选评估，不猜设备型号、开关用途或实物尺寸。

## 接入结果

11 个 USDZ 和其余源文件共 18 个已复制到 `assets/USD001/`。原包 CRC、逐文件 SHA-256、
贴图解析均通过。生成项目内相对路径引用的总览和 11 个单资产引用层，Isaac Sim 6.2
独立预览全部成功。现有双臂 RM65 人形场景保持运行，新资产未在其运行期追加物理结构。

**这批补充的是柜体外观，不是现成的操作机构。** 每份文件只有 1 个合并 Mesh，
关节、刚体、碰撞 API 都为 0。材质分组与不相连几何还在，但没有运动学部件划分。
因此本批新增“已经可以直接执行并验收”的动作数是 **0/22**。

从改造候选看：优先 4 类/8 个动作，另有 2 类/4 个动作需确认旋钮语义；
其余 5 类/10 个动作没有补齐专用机构。所有“候选”都尚未做人形接触验证。

## 对应 11 类、22 个动作

| 类别 / 动作编号 | 两个功能动作 | 新资产覆盖 | 还要做什么 |
|---|---|---|---|
| 1 / 1-1、1-2 | 远方、就地 | **功能待确认**：010 旋钮可作外观候选 | 确认选择开关用途和两档角度，拆出旋钮、补转轴/碰撞/定位及状态反馈 |
| 2 / 2-1、2-2 | 合闸、分闸转换开关 | **功能待确认**：010 旋钮可作外观候选 | 确认是否确为分合闸转换开关、中间位/保持/弹回特性；不能由外观指定功能 |
| 3 / 3-1、3-2 | 旋至目标档、回初始档 | **优先改造**：010 | 分离旋钮帽/底座，补旋转关节、碰撞、限位、档位和实际角度反馈 |
| 4 / 4-1、4-2 | 按下灯亮、复位灯灭 | **优先改造**：010；002/004/006 备选 | 确认哪些圆件是按钮/灯，分离按钮帽，补直线关节、回位、发光材质和正确逻辑映射 |
| 5 / 5-1、5-2 | 指定按钮、复位 | **优先改造**：010；002/006 备选 | 补目标 ID、可动按钮、独立输出状态及相邻误触判断；不额外贴铭牌 |
| 6 / 6-1、6-2 | 螺丝压板投出、投入 | **仍缺机构** | 需要螺柱、螺母/旋钮、压板、端子座完整装配；当前封闭柜体外观不能代替 |
| 7 / 7-1、7-2 | 提拉压板提起、落回 | **仍缺机构** | 需要提拉件、导向、落孔、摆动和复位机构；009 的顶部提手不算 |
| 8 / 8-1、8-2 | 复合急停操作、复位 | **仍缺机构** | 需要“外圈旋转到位＋中心按压”的双部件结构，普通圆件/旋钮不能直接算急停 |
| 9 / 9-1、9-2 | 断路器合闸、分闸 | **仍缺机构** | 需要独立断路器本体、手柄/按钮及状态机构；003/006 整柜外形和操作口不足以认定 |
| 10 / 10-1、10-2 | 锁孔解锁、锁紧 | **仍缺关键装配**，仅有柜门把手线索 | 需要匹配扳手/钥匙、孔槽、锁芯、锁舌/锁扣；才能验证插入旋转、锁紧及门联动 |
| 11 / 11-1、11-2 | 开门、关门 | **优先改造**：001/005/010；其它柜体备选 | 拆门、柜壳和把手，必要时重建门片/内腔；补铰链、碰撞、限位和锁扣状态 |

优先 4 类是 3、4、5、11；功能待确认 2 类是 1、2；缺机构 5 类是 6～10。

门的限制尤其要注意：008 只有 16 个顶点、12 个面、2 个不相连分量（盒体与把手），
并没有可直接分离的门板/柜壳/内腔。给整个盒体加转轴会让整个柜子转动，不能算开门。
其它柜体的门边界也需要逐个拆分/重建，不能由“看得到门缝”推断为机构齐全。
