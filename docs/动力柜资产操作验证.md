## 当前能做哪些操作

此轮只验证柜体自身的物理运动与灯光，不加载机器人。用 PhysX 刚体反馈计算实际位移、转角，
没有把写入 USD 的目标值当作执行结果。每个关节完成两次往返循环。

| 部件 | 操作 | 实测反馈 | 结论 |
|---|---|---|---|
| Btn04～Btn07，4 个操作按钮 | 按下、回位 | 目标 -6 mm，实际约 -5.89 mm；回位残差约 -0.11 mm | 通过 |
| Knob01，面板标注分闸/合闸/0 | 正反旋转、回零 | +45° → +44.73°；-45° → -44.52°；回零约 -0.058° | 通过 |
| Knob02，面板标注启动/停止 | 正反旋转、回零 | +45° → +44.94°；-45° → -44.86°；回零约 -0.062° | 通过；实际功能档位仍需确认 |
| Lock_Btn，锁按钮 | 按下、回位 | 目标 -5 mm，实际约 -4.91 mm；回位残差约 -0.09 mm | 修正关节配置后通过 |
| Lock_Handle，锁柄 | 正反旋转、回零 | 目标 +45°，稳定后约 +36.4°；短时正反均约 ±36.3° | 会运动，但未通过 2° 到位误差要求 |
| Btn01～Btn03，顶部指示灯 | 亮/灭 | 可分别切换发光材质并恢复原材质 | 视觉状态；未接入电气逻辑 |

资产给 Btn01～Btn03 也建了 6 mm 滑动关节，运动测试通过；但铭牌是分闸/合闸/储能指示，
不应因此将这三个灯作为机器人按压任务。灯与按钮的逻辑对应关系尚无权威数据，未擅自绑定。

当前没有门铰链、锁舌/锁扣联动、锁孔插拔配合、螺丝压板、提拉压板、急停和断路器机构。
因此锁柄能转不等于门已解锁，也不能用它直接完成开门任务。

## 复现与单独操作

先检查 `GET http://127.0.0.1:18765/health`。已有服务且加载了机器人时，不要直接覆盖场景。
此轮启动的是只加载柜体的独立 GUI 会话，启动日志在 `outputs/cabinet_inspection/isaacsim.log`。

```bash
# GUI 启动：scripts/run.sh 已处理 ROS Python/动态库污染。
DISPLAY=:1 XAUTHORITY=/run/user/1000/gdm/Xauthority \
ISAAC_PYTHON=/home/jy/micromamba/envs/isaacsim6.0/bin/python ./scripts/run.sh

# 在空白服务里挂入独立测试层。
python3 scripts/cabinet_inspect.py setup --repair \
  --asset /home/jy/VLA/simManager/data/environment/dongligui/dongligui_scene.usda

python3 scripts/cabinet_inspect.py exercise --tag repaired
python3 scripts/cabinet_inspect.py set --name Btn04 --target -0.006
python3 scripts/cabinet_inspect.py set --name Btn04 --target 0
python3 scripts/cabinet_inspect.py set --name Knob01 --target 45
python3 scripts/cabinet_inspect.py set --name Knob01 --target -45
python3 scripts/cabinet_inspect.py light --name Btn01 --on
python3 scripts/cabinet_inspect.py light --name Btn01
python3 scripts/cabinet_inspect.py capture
```

输出目录可用 `--output` 指定，服务地址可用 `--url` 指定。直线单位米，旋转单位度；
脚本拒绝超出资产限位的目标。setup 会替换 `/World/Cabinet` 并 reset 物理世界，适用于独立验收场景。
