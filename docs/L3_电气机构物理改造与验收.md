当前GUI `/World/L3Station` 已显示全部15件。左侧保留绿色按钮0(1)、object_3旋钮、object_14压板，右侧新增12件按按钮/旋钮/压板分行排列。保留原动力柜和Oxford面板；旧Oxford面板沿Y移开1.65m，避开全量展示板。窗口 **电力柜动作控制** 可按编号选择任意一件，并点击按压/释放、指定旋钮档位、压板投出/投入。单列“人形右手：按压绿色按钮并复位”执行真实接触，其余为机构力/扭矩直接操作。中文界面、停止与反馈详见 [操作说明](电力柜中文动作插件.md)。

## 验收结果与证据

1. **独立机构75/75次循环通过**：每件5次，按钮20次、旋钮30次、压板25次。使用外部广义力/扭矩，未把机构关节传送到终点。TGS，240Hz。旋钮最大档位偏差约0.317°；压板受锁止测试扭矩时最大摆角约0.0058°，等效轴移误差小于0.000171mm。压板检查包括未松禁止摆动、两端旋松、投出、投出时禁止紧到底、返回、旋紧恢复连接。
2. **当前GUI夹具流程通过**：按压/释放、旋钮切档、压板投出/投入均有实际关节反馈；结束时压板 connected=true，按钮已回位。证据 `outputs/l3_operable/live/ui_checks.json`。
3. **人形真实接触**：仅绿色object_0_variant执行了右手真实指垫按压验证；按钮弹簧目标始终保持预载值，未下发按钮按压目标。接触报告记录了机器人与帽体的非零冲量。三次按下亮灯、松手回位通过，触发行程约3.30/3.04/2.97mm，每次均有独立非零接触冲量；原50DOF整机位置与雅可比保持有限值。原三次数据保存在 `live/robot_button_before_plugin.json`；新增中文插件入口验证保存在 `live/plugin_robot_result.json`。
4. **力—行程仍有数值误差**：独立PGS恒力检查在3.8N得到约2.600mm，符合参考线性弹簧；TGS同参数在240Hz约2.237mm，偏差约0.363mm。PGS在现有移动人形整机场景出现底盘漂移，因此交付保留TGS，恢复机器人站位，未以更换求解器掩盖整机问题。当前版本可用于动作/接触/状态流程，**不能作为实物按压力或扭矩标定**。
5. 原60Hz下GUI螺母易跨过锁紧终点；当前场景物理步进改为240Hz并重新检查。此为当前会话设置，未修改全局启动配置。独立与当前GUI检查数据分别留存。

## 使用、复现与后续实测

操作命令见 `assets/l3_operable/README.md`。恢复独立75循环：

```bash
env -u DISPLAY -u VIRTUAL_ENV -u PYTHONPATH -u LD_LIBRARY_PATH -u ROS_DISTRO \
  OMNI_KIT_ACCEPT_EULA=YES PYTHONUNBUFFERED=1 \
  /home/jy/micromamba/envs/isaacsim6.0/bin/python scripts/validate_l3_operable.py \
  assets/l3_operable --output outputs/l3_recheck --cycles 5 --solver TGS
```

实测补充：每种件的型号与功能对应、按钮直径/凸出/总行程/触发与释放力、旋钮档位角度/旋向/保持或自复位/扭矩曲线、压板高宽深/螺距/旋松圈数/锁紧扭矩/接触间隙。修改profile到新目录重建，校准后再做夹具与整机接触验收，不能在活动场景中原位覆盖USD。
