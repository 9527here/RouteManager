# 人形操作电柜：接触验证

日期：2026-10-29；环境：Isaac Sim 6.2；机器人：项目的双 RM65＋CT 夹爪人形整机，50 DOF。
柜体继续用无额外铭牌的 dongligui 物理源，原资产不写回。

## 已验证结果

### Btn05 按下、退出、回位

右手保持闭合，以两个真实指垫前端按压按钮；没有添加探针、固定吸附约束或代替夹爪的物体。
按钮的 `drive:linear:physics:targetPosition` 全程为 0，只由原有回位弹簧抵抗按压。

| 机身状态 | 实际最大按下量 | 退开后的回位残差 | 结果 |
|---|---:|---:|---|
| 初始升降高度 | 5.440 mm | 0.0052 mm | 通过 |
| 升降目标 -0.08 m | 5.368 mm | 约 -0.00006 mm | 通过 |

软件验证条件：行程至少 4.5 mm、回位残差小于 0.5 mm、存在机器人与按钮接触报告，
并出现非零接触冲量。第二次测试记录最大单接触冲量约 0.0345 N·s；它不是操作力、扭矩或真机标定值。

这证明按钮的运动来自机器人接触，而不是直接给按钮关节发按下目标。尚未根据猜测把 Btn05
绑定到某个指示灯；需要设备的按钮—灯/输出对应表。

### Knob01 夹持、正反转、回零、松开

从实际 mesh 量得夹持方向外包络宽度约 27.266 mm，用现有夹爪标定表换算开合指令。
先在空中测目标闭合角下的 TCP 偏移，再张开接近，避免四连杆沿工具轴漂移导致夹空。

本轮是**自由转轴的接触传动验证**：夹住后在测试层暂时把旋钮主动驱动的 stiffness、damping、
maxForce 置零。未给旋钮写任何转角目标，转动由手臂与夹爪接触带动。
原主动驱动是位置伺服，不代表真实开关的档位阻力，不能拿它与机器人硬顶。

第一轮工具开环滚转时约得到 +35.87°、-26.60°，存在滑移/几何传动误差。
第二轮对语义目标点使用旋钮真实角度反馈，有限次修正工具滚转，结果如下：

| 目标世界转角 | 实际世界转角 |
|---:|---:|
| +30° | +28.630° |
| 0° | +0.731° |
| -30° | -29.374° |
| 0° | -1.152° |

四个状态误差均小于 2°，且报告了非零接触冲量。完成后恢复原驱动
`stiffness=500, damping=30, maxForce=5000, targetPosition=0`，再松开并退出。
第一轮接触报告冲量全零，已保留原始结果；第二轮最大单接触冲量约 0.0788 N·s。

**此结果不等于分/合闸设备验收完成**：没有真实档位定位、保持/弹回特性和操作扭矩数据，
没有模拟真实电气分合状态，也没有做负载扭矩验收。

## 站位、升降和轨迹

- 原预览位置无法保证正面按压可达。底盘实际前进约 120.65 mm，横向偏移约 -0.50 mm。
- 正面夹持中央旋钮需要降低机身；升降目标为 -0.08 m，实际约 -0.082 m，处于真实限位内。
- 预接近段保持 60 mm 间隔；近接近/按压分阶段读取实际手臂和按钮状态。
- 运行时从当前人形基座世界位姿建立 URDF FK，用 SciPy 最小二乘解六轴目标。
  未用旧臂关节名、雅可比表或 Isaac 质心雅可比替代 TCP 雅可比。
- 只向右臂六关节和明确指定的升降关节发指令；没有回灌整机反馈。
- 抓取测试没有更改机械臂、夹爪的驱动参数，没有往柜体贴额外铭牌，没有新建相机。

## 复现

在已完成 `docs/电柜资产清单与人形场景.md` 的人形＋柜体场景后：

```bash
python3 scripts/cabinet_contact.py advance
python3 scripts/cabinet_contact.py button --name Btn05
python3 scripts/cabinet_contact.py lower
python3 scripts/cabinet_contact.py knob --name Knob01
```

advance 会检查此前站位记录，已在该站位时不再前进；lower 使用绝对升降目标 -0.08 m。
执行对象仍须是这份人形与柜体场景，不能把本脚本直接用于其它机型或其它关节命名。

客户端显示 HTTP 执行结果；动作是否通过须看 JSON 的 `pass`，不能用“HTTP success”代替。
柜体动作过程中一旦出错会退出接近位置；旋钮的临时驱动覆盖在 finally 中恢复。

## 文件

均位于 `outputs/cabinet_humanoid/`：

- `base_approach.json`、`lift_adjustment.json`：底盘/升降的实测位置。
- `button_plan.json`：机器人预接近至按压的 IK 轨迹。
- `button_contact_initial_height.json`、`button_contact.json`：两次按钮接触、行程和回位。
- `knob_contact_first.json`、`knob_contact.json`：开环及反馈修正后的旋钮结果，保留失败数据。
- `button_pressed.png`、`knob_positive.png`、`knob_negative.png`、`contact_final.png`：原始视口截图。
- `contact_final_health.json`：50 DOF、link/Jacobian 均有限，按钮回位目标为 0、旋钮驱动已恢复。

当前机器人停在接近站位，右手已退离控件。进一步接近真机，需要补按钮输出对应关系、
开关档位角与保持/复位逻辑、扭矩/按压力等数据，而不是靠视觉演示推定。
