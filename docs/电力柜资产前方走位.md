# 按实际名称选择资产，先走位再操作

> 2026-11-02最新要求：资产操作先使胸部垂直朝向柜门／面板，再锁定对正后的朝向做X/Y平移；手动左右横移仍固定起始yaw、全程wz=0。先收臂、真实停轮对舵并稳定，再从0加速。本文下方±55°临时行驶朝向已撤销，不能用它代替纯侧移。面向目标来自操作面法线，不能覆盖成起始yaw，也不等于身体中心看向按钮。

中文“电力柜动作控制”按实际机构名称选择按钮、选择开关或螺丝压板，原编号只保留为来源标识。资产在USD中的展示名同步更新，prim路径不改。电气用途没有实物对照的选择开关，暂不命名为“合闸/远方”等功能，详见[名称依据](资产实际名称与功能待确认.md)。

点击动作后的顺序为：**选择资产 → 规划前方操作位 → 四轮八驱物理驶入 → 确认位置、朝向与停稳 → 执行动作**。也可以单独点击“移动到所选资产前”。途中“停止底盘”或“停止当前动作”会取消尚未执行的操作并刹停，不会继续触发机构。

L3、旧动力柜、Oxford及人形按钮入口共用前置走位门控。机构直接驱动和人形真实接触仍分别标记，走位不会把机构驱动变成人形接触示教。独立Isaac Lab机构批采不包含机器人底盘，不套用桌面走位门控。

## 底盘与参考设置

本机真实模型包含四个 `caster_*_joint` 和四个 `*_wheel_joint`。转向关节用位置目标，滚轮用速度目标，支持前后、横移和原地转；模型半径、转向轴、左右滚轮符号从URDF读取，不再用旧四轮差速冒充。原URDF/L2舵角为±5°；用户已授权当前仿真参考±90°，待实测。覆盖仅在会话USD层和物理张量生效，不写回源文件。

`assets/l3_operable/mobile_operation_profile.json`保存参考控制设置：常规巡航上限0.25m/s、加速度上限0.15m/s²、最大转速0.35rad/s；靠近目标减速。模型当前转向力矩、滚轮力矩、摩擦、刚度和阻尼保持原值。

当前操作位沿用旧RM65绿色按钮接触验收的相对站位，包含右臂横向偏置；并非新URDF的通用站位。目标位置由所选资产当前世界位姿换算，新的带外壳机器人到后需要重标。参考位置进入门限18mm、滞回保持范围25mm，朝向进入2°、保持3°；两者仅为仿真到位判据。停稳还要求真实根位置与8关节位置窗口有界，不能只检查速度指令为0。

## 为什么旧动作很慢以及这次的处理

- 旧验证速度上限只有0.065m/s，而且每次都先退离再对舵。现在净空允许时使用直接路径。
- ±90°硬限位处有相差180°的等效舵角分支。侧移时车身反作用和小幅航向修正会使解反复翻转，导致频繁停轮。长距离侧向段改为采用留出35°舵角余量的临时车身朝向，最后再对正资产；必要时退到外侧暂存位。超过65°余量阈值时先修正车身，不硬顶极限或默许侧滑。
- 矩形包络检查改为NumPy批量计算：80个实际场景候选姿态与原标量检查逐项一致，基准耗时约0.236s→0.019s。四个舵轮另加由实际几何生成的转舵扫掠包络，不能只冻结初始轮胎形状。
- 物理控制保持240Hz，界面更新降到10Hz，减少每个物理子步重排所有按钮。停车时只在首帧一次性保持实测舵角，避免继续追旧目标产生反扭矩。
- 人形原来每个小段至少180帧、按压每路点200帧，另有固定等待。现改为按距离与参考速度计算帧数，并根据真实到位/速度反馈提前结束等待；速度仍受URDF和PhysX模型限速约束。

人形参考关节速度为0.5rad/s、按压TCP速度为0.02m/s，均未按真机标定。触发2.9mm即停止深入、0.025rad跟踪误差停止、取消和非有限状态检查保留。没有通过提高电机力矩或改摩擦来提速。

## 验收入口与证据

```bash
python3 scripts/setup_cabinet_actions.py       # 空白服务初始化；已有工位只打开窗口
python3 scripts/l3_station.py approach_selected --asset object_19
python3 scripts/validate_mobile_asset_actions.py  # 实际走位后操作绿色按钮、三档开关
```

- `outputs/mobile_operations/live_actions_validation.json`记录首次操作的真实到位/停稳状态、机构反馈及操作期间的底盘漂移。首次门控与之后漂移分开记录，不能把之后微小漂移误称为“未到位提前操作”。
- `outputs/mobile_operations/stop_validation.json`记录走位途中停止，待操作已取消、机构未触发及实际刹停。
- `outputs/swerve_base_audit/`包含原模型、±90°会话覆盖、前后/侧移/转向及停稳窗口证据。

导航使用当前工位的静态碰撞几何与连续包络检查，并按真实物理位姿闭环。遇目标占用、路径受阻、异常倾角或无有效进展会停止并取消待操作。此版本不声称具备通用地图定位或动态行人避让，自碰撞工作按用户要求暂缓。

### 本次最终实测

绿色按钮与方座三档开关的“走位—停稳—机构动作”均通过，后者净移动约1.086m。操作期间底盘漂移分别0.72/0.53mm，朝向漂移约0.096/0.098°。实际移动约33mm后中途停止，制动阶段继续移动约5.9mm；待操作已取消，机构未触发。

提速人形真实接触另行复测通过：按钮行程3.138mm，最大接触冲量0.01907Ns，释放回位并回撤；当次提交时已在目标前方，不含底盘导航，含规划与完整动作约23.75秒。它与机构直接驱动验收分别保存。
