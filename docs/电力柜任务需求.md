## 一、梳理原则

1. **功能动作才计数**：投出/投入、远方/就地、合闸/分闸、开/关、提/落等。
2. **过程步骤不单列**：识别、对准、插入、确认、保持、复位中的“保持”并入对应动作。
3. **双向动作保留去程/回程**：因为方向、夹持、力/扭矩不同，且文档验收常要求“可重复切换”。
4. **同一功能的多步骤合并**：如螺丝压板“旋松+拨动”合为“投出”，“拨动+旋紧”合为“投入”。

## 二、逐设备梳理

| 设备 | 原动作 | 梳理后功能动作 | 说明 |
|---|---|---|---|
| 切换开关 | 远方、就地 | **2 个**：切至远方、切至就地 | 去程/回程方向不同，保留 2 个；“识别、止挡确认”为步骤 |
| 分合闸转换开关 | 合闸、分闸 | **2 个**：合闸、分闸 | 同上 |
| 旋钮开关 | 目标档位、多档位切换、复位 | **2 个**：旋至目标档、复位回初始档 | “多档位切换”是过程，并入“旋至目标档”；复位是独立功能，保留 |
| 按钮和指示灯 | 按压灯亮、复位灯灭 | **2 个**：按下（灯亮/翻转）、复位（灯灭/恢复） | 两个方向状态不同，保留 2 个 |
| 操作指示器 | 按压目标按钮、复位逐个操作 | **2 个**：按压目标按钮、复位 | “逐个操作”是过程，并入按压；复位保留 |
| 螺丝压板 | 4 个 | **2 个**：投出、投入 | 已合并 |
| 提拉压板 | 3 个 | **2 个**：提起、落回复位 | 已合并 |
| 急停按钮 | 旋转外圈、按压中间、复位 | **2 个**：急停操作（旋转外圈+按压）、复位 | 旋转和按压是同一急停功能的连续步骤，合并为 1 个；复位独立 |
| 断路器 | 合闸、分闸、状态确认/复位 | **2 个**：合闸、分闸 | “状态确认/复位”是过程，并入分/合闸判据 |
| 螺丝孔 | 插入、旋转解锁、关门后锁紧 | **2 个**：解锁（插入+旋转）、锁紧（反向旋转） | 插入是步骤；开门/关门另列 |
| 开门/关门 | 识别、开门、保持、关门、确认锁固 | **2 个**：开门、关门 | 识别、保持、确认锁固是步骤，并入开/关 |
