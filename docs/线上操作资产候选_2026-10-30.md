# 线上操作资产候选

核对日期：2026-10-30。针对《电力柜任务需求.md》的旋钮、按钮、急停、断路器、门锁和柜门。
本轮核对公开网页、仓库 README/LICENSE 和部分 Xacro 文本，没有下载模型包或作 Isaac 接触验收。

## 1. 优先：Oxford manipulation_playground

- 仓库：https://github.com/ori-arg/manipulation_playground
- 许可证：https://github.com/ori-arg/manipulation_playground/blob/master/LICENSE
- 仓库许可实查为 **BSD-3-Clause**，版权归 Oxford Dynamic Robot Systems Group。
- 面向 ROS 1/catkin、RViz、Gazebo；不是 Isaac Sim USD 原生包。
- 包含球阀、截止阀、闸阀、针阀、手轮，以及下列操作设备。

| 设备 | 已查实结构 | 对本项目的意义 |
|---|---|---|
| e_stop_button | Xacro 有 button_twist_joint（revolute）、button_joint（prismatic），3 组 collision；使用基本几何，无外部 mesh 引用 | 普通急停按压、旋转解锁和复位的优先候选 |
| isolator_switch | Xacro 有 switch_joint（revolute），3 组 collision；基本几何 | 两态旋转开关、状态反馈的基础候选，不能直接指定为远方/就地或分合闸 |
| safety_switch | Xacro 有 switch_joint（revolute）、2 组 collision；外部 DAE 分为 base 和 lever | 手柄式安全开关操作候选；不是已确认的断路器 |

直接文件入口：

- [急停 Xacro](https://github.com/ori-arg/manipulation_playground/blob/master/manipulation_playground_articulated_devices/devices/e_stop_button/model/e_stop_button.urdf.xacro)
- [隔离开关 Xacro](https://github.com/ori-arg/manipulation_playground/blob/master/manipulation_playground_articulated_devices/devices/isolator_switch/model/isolator_switch.urdf.xacro)
- [安全开关 Xacro](https://github.com/ori-arg/manipulation_playground/blob/master/manipulation_playground_articulated_devices/devices/safety_switch/model/safety_switch.urdf.xacro)

README 明确说明：switches 用 Python 脚本依据手柄位置维护激活状态并发布 activation_state；
动力学可选 none/normal/stiff，但参数没有按实际设备标定。它们是有用的反作用力表示，
不能当真实扭矩验收值。Gazebo/ROS 控制器和状态脚本不会随 URDF 自动转换到 Isaac。

急停的行为是“按下激活、逆时针旋转解锁”，不等同动作文档的“先旋转外圈、再按中心”。
虽然它有旋转、直线两个关节，仍需按目标实物确认组合与顺序。

接入路线：展开 Xacro → 补 package mesh 路径（安全开关有 DAE）→ 用 Isaac Sim 6.2
导入分件和关节 → 在 RouteManager 主线程迁移状态/复位逻辑 → 用现有人形做接触验收。

## 2. 选择开关／按钮／灯：Schneider Harmony 厂家 CAD

- [ZB4BD2 官方产品入口](https://www.se.com/ca/en/product/ZB4BD2/head-for-selector-switch-harmony-xb4-metal-black-22mm-2-positions-stay-put/)
- 页面对该型号描述为 22 mm、两位、保持型选择开关头，并列 CAD 入口。
- 可作为动作 1/2/3 类的真实几何候选；实际用途和现场型号仍待确认。
- CAD 文件格式、分件和下载条款需选定文件后检查；不能仅由产品页认定已带可动关节。
- 同系列按钮/灯需要按实际设备选型，不能把所有 Harmony 型号混作同一机构。

厂家 CAD 不是已确认的开源资产许可，模型再分发和项目交付需要核对其具体下载条款。

## 3. 断路器：Schneider TeSys GV6P 官方 STP

- [官方 CAD 下载页](https://www.se.com/id/id/download/document/MCADPD0004073_3D-CAD/)
- 网页实查列有 `MCADPD0004073_3D-simplified.stp`，大小约 1.3 MB。
- 页面对应 TeSys GV6P 旋转手柄断路器 CAD，是动作 9 的几何候选。
- **simplified** 不能当作内部机构或可动分件已经齐全的证明。本轮未下载 STP，尚不知道
  手柄是否能单独拆分；仍需关节、限位、状态及碰撞配置。
- 具体型号是否符合用户实际设备、以及厂家 CAD 使用条款均需核对。

## 4. 门锁、锁舌、铰链：EMKA 官方 CAD

- [官方 CAD 服务说明](https://www.emka.com/ro/servicii/date-cad/)
- 官方搜索索引说明提供 STEP、IGES；登录产品区可取 CAD、产品表、零件清单。
- [官方机柜锁具总目录](https://www.emka.com/fileadmin/catalog/catalog_downloads/pdf/en/Ingenious_Locking_Technology_for_Cabinets_and_Enclosures_EN_06-2020_Web_-_search_option.pdf)
  包括 quarter-turn 锁、锁舌/附件、钥匙、铰链等类别。
- 对动作 10/11 有价值：按型号组合锁芯/锁舌/工具，再配现有柜体门片。
- 本轮未登录或下载具体装配，不能认定锁芯内部机构、钥匙配合或完整门锁联动已经提供。
- 使用条款以厂家 CAD 下载规定为准。

## 5. 通用柜门：PartNet-Mobility / SAPIEN

- [数据集入口](https://sapien.hillbot.ai/)
- [官方使用条款](https://sapien.hillbot.ai/terms)
- [官方下载 API 文档](https://sapien-sim.github.io/docs/api/sapien.asset.html)
- 数据集提供可动部件及运动学标注，通用柜门/抽屉是可用方向；不能据此宣称含目标电力柜机构。
- 官方条款限定非商业研究与教育，要求账户权限；SAPIEN 引擎开源许可不等于数据集许可。
- 不作为商业交付场景的默认来源，也不能用通用门模型代替锁孔—锁舌—柜门闭环。

## 建议顺序

1. 先评估 Oxford 的 e_stop_button、isolator_switch、safety_switch，关节/碰撞/状态逻辑基础最好。
2. 用 Schneider 的具体型号 CAD 补断路器和需要真实外观的面板控件。
3. 用 EMKA 具体锁具和铰链补 USD001 的门锁机构；压板继续向设备厂家/机械同事要分件 CAD。

所有来源仍需在本项目人形与 Isaac Sim 6.2 上验证；本轮没有把网上资产记为“已经能执行”的新增动作。
